# HackerRank Orchestrate – June 2026 (My Solution)

This repository contains my solution for the HackerRank Orchestrate June 2026 challenge.  
The task was to build a system that verifies **visual evidence for damage claims** across three object types: **cars**, **laptops**, and **packages**.
